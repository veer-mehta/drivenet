rivenet

everything above happens in your browser. this site stores nothing and only serves this page.

why

sign-in goes through a google project. the default one only handles sign-in. make your own to not depend on it. your vault belongs to the project it was created with, so keep using the same one.

steps
  1. open console.cloud.google.com, create a project and enable the google drive api.
  2. on the oauth consent screen choose external, add yourself as a test user and add the scope .../auth/drive.appdata.
  3. under credentials, create an oauth client id of type web application.
  4. add as an authorized javascript origin.

running this site yourself? set GOOGLE_CLIENT_ID in .env and this step goes away.

account

there is no password recovery. forget it and the files are gone.

connect

this vault keeps a copy in more than one account. connect the others so every copy stays up to date.

    blocks are spread across the drives you pick. pick one to keep the whole file on that drive.

    settings

    block size, mb

    plaintext bytes per block. drive multipart uploads cap at 5 mb.

    transfers per drive

    concurrent block requests per account.

    scrypt cost

    n = 2^x, r = 8, p = 1. memory is 32 mb at 2^15 and doubles per step. applies on the next password change.

    remember this device

    skips the password on this device until it expires. the vault key stays wrapped by a non-extractable webcrypto key. lock and logout clear it.

    stack

    blocks
    aes-256-gcm, random 96-bit nonce. aad is file id, block index and block count.
    file keys
    hkdf-sha256 from the 256-bit master key, one key per file.
    vault
    fernet (aes-128-cbc, hmac-sha256). the master key is wrapped with scrypt.
    storage
    google drive appDataFolder, scope drive.appdata. a vault copy in every account.
    runtime
    python 3.12 on pyodide 0.26.4 in a web worker, with the cryptography package.
    device
    vault key wrapped by a non-extractable webcrypto aes-gcm key in indexeddb. only the ciphertext is stored. the password is never stored.
    network
    the browser talks to googleapis.com directly. this site serves static files only.
