Google sign-in isn't set up yet.

  1. In console.cloud.google.com, create a project and enable the Google Drive API.
  2. On the OAuth consent screen choose External, add yourself as a test user, and add the scope .../auth/drive.appdata.
  3. Create an OAuth client ID of type Web application.
  4. Add as an authorized JavaScript origin.
  5. Paste the client ID into web/config.js and reload.
